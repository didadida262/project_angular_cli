## 开发服务器

运行 `npm start` 启动开发服务器。打开浏览器访问 `http://localhost:4200/`。

## 构建

运行 `npm run build` 构建项目。构建产物将存储在 `dist/` 目录中。

## 运行测试

运行 `npm test` 执行单元测试。

## 代码规范

运行 `npm run lint` 检查代码规范。
运行 `npm run format` 格式化代码。
